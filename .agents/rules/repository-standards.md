# Repository Standards & Language Policy

## Language Requirement
- **English Only**: All source code, Lua variables, function names, code comments, docstrings, documentation files (`README.md`, guides, notes), and Git commit messages MUST be written strictly in English.
- The user may converse in Spanish or another language, but any files created or modified inside this repository must remain 100% in English.

## Commit Message Conventions
- Follow Conventional Commits:
  - `feat(scope): ...` for new features or plugins.
  - `fix(scope): ...` for bug fixes or path corrections.
  - `docs(scope): ...` for documentation updates.
  - `refactor(scope): ...` for refactoring Lua configurations.
